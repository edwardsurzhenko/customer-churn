# Первые модели: validation

Следующий эксперимент: [сравнение четырёх моделей](comparison.md).

Результаты получены командой `python scripts/train_baseline.py` на фиксированной
версии IBM Telco Customer Churn. Полные метрики, SHA-256 данных и версии библиотек
сохранены в [baseline.json](baseline.json).

## Протокол

- Стратифицированное разбиение, `random_state=42`: train 4 225, validation 1 409,
  test 1 409 клиентов.
- Числовые признаки: `tenure`, `MonthlyCharges`, `TotalCharges`; остальные
  16 признаков кодируются как категориальные. ID и целевая переменная исключены.
- В логистической регрессии используется медианное заполнение числовых пропусков,
  StandardScaler и OneHotEncoder. Все преобразования обучены только на train.
- DummyClassifier с `strategy="prior"` выдаёт одинаковую оценку риска для всех
  клиентов. При пороге 0.5 он предсказывает только отсутствие оттока.
- Настройки логистической регрессии: `C=1`, `max_iter=2000`, стандартный solver
  `lbfgs`, без весов классов. Настройки и порог пока не подбирались.

## Результаты

Метрики вычислены только на validation, положительный класс — `Churn=Yes`.
Для accuracy, precision, recall и F1 использован порог 0.5.

| Модель | ROC-AUC | Average precision | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| Dummy prior | 0.5000 | 0.2654 | 0.7346 | 0.0000 | 0.0000 | 0.0000 |
| Logistic regression | 0.8360 | 0.6424 | 0.8027 | 0.6579 | 0.5348 | 0.5900 |

Для dummy precision указан как 0 при отсутствии положительных прогнозов
(`zero_division=0`). Average precision (AP) рассчитана функцией
[`average_precision_score`](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html);
это не трапецеидальная площадь под PR-кривой.

Матрица ошибок логистической регрессии:

| Факт / прогноз | Останется | Уйдёт |
|---|---:|---:|
| Остался | 931 | 104 |
| Ушёл | 174 | 200 |

Это начальная оценка на одном разбиении. Финальный test не оценивался;
выбор модели, порога и анализ качества кампании остаются следующими этапами.
