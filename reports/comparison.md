# Сравнение четырёх моделей

Команда воспроизведения:

```bash
python scripts/train_baseline.py --compare-models
```

Полный отчёт: [comparison.json](comparison.json).
Результаты первоначального эксперимента: [baseline.json](baseline.json).

## Протокол

- Те же данные и ID разбиения, что в первом эксперименте; `random_state=42`.
- Train: 4 225 клиента; validation: 1 409; test: 1 409.
- Все обучаемые преобразования и модели подгоняются только на train.
- Общие для трёх моделей заполнение числовых пропусков медианой,
  заполнение категориальных пропусков наиболее частым значением и one-hot кодирование.
- StandardScaler применяется только к числовым признакам логистической регрессии.
- Метрики вычислены на validation, положительный класс — `Churn=Yes`.
- Порог 0.5 фиксирован для precision, recall, accuracy и F1; он не подбирался.
- Для предварительного сравнения ранжирования используется average precision (AP).
  ROC-AUC и метрики при пороге приведены дополнительно.
- Начальные конфигурации заданы до запуска; поиска гиперпараметров не проводилось.

## Начальные настройки

| Модель | Основные настройки |
|---|---|
| DummyClassifier | `strategy="prior"` |
| LogisticRegression | `C=1`, `max_iter=2000`, `solver="lbfgs"` |
| RandomForestClassifier | 300 деревьев, `max_depth=8`, `min_samples_leaf=5`, `max_features="sqrt"`, bootstrap |
| GradientBoostingClassifier | 150 деревьев, `max_depth=2`, `learning_rate=0.05`, `min_samples_leaf=10`, `loss="log_loss"` |

## Результаты validation

| Модель | ROC-AUC | AP | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Dummy prior | 0.5000 | 0.2654 | 0.0000 | 0.0000 | 0.0000 |
| Logistic regression | 0.8360 | 0.6424 | 0.6579 | 0.5348 | 0.5900 |
| Random forest | 0.8384 | 0.6402 | 0.6755 | 0.4786 | 0.5603 |
| Gradient boosting | 0.8391 | 0.6451 | 0.6750 | 0.5053 | 0.5780 |

В данном запуске бустинг имеет наиболее высокие AP и ROC-AUC. Разница AP
с логистической регрессией составляет около 0.0027. Это результат на одном
разбиении без оценки неопределённости; окончательный победитель не выбран.
При текущем пороге у логистической регрессии выше recall и F1.

Фактические максимальные глубины: все 300 деревьев леса достигли глубины 8,
все 150 деревьев бустинга — глубины 2. Эти значения относятся к наиболее длинным
путям каждого дерева, а не ко всем его ветвям.

Следующие эксперименты: обработка пропусков, настройки моделей, выбор порога
и оценка качества списка из K клиентов. Финальный test не оценивался.
